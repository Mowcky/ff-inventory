Import Excel files

Use this only if you have been updating the Excel files instead of the website. Importing replaces everything on the website, including changes made there. Nothing is uploaded from this page; it all happens in your browser.

  1. Download the latest Excel files from your SharePoint Employees folder (select them all, then Download).
  2. Drop all of them below. The template and any files without a position number are skipped.
  3. Check the list, then choose Download data.json.

Files read

PositionNameOfficeItemsHistory

Put it on the website

  1. Open your repository on github.com.
  2. Choose Add file, then Upload files, and drop in the data.json you just downloaded.
  3. Choose Commit changes. The website updates within a minute or two, and every QR sticker keeps working.
